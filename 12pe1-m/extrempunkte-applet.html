Extrempunkte: von f zu f′ und f″

Wählen Sie eine Funktion und ziehen Sie den Punkt auf der x-Achse. Erst selbst skizzieren, dann f′ und f″ einblenden. Der Rechenweg unten kommt Schritt für Schritt.

Merksatz und Aufgaben für zu Hause
Merke Notwendig: An jedem Extrempunkt gilt f′(x0) = 0. Aber nicht jede Stelle mit f′(x0) = 0 ist ein Extrempunkt (x3 bei 0).
Hinreichend: f′(x0) = 0 und f″(x0) < 0 ⇒ Hochpunkt; f′(x0) = 0 und f″(x0) > 0 ⇒ Tiefpunkt. Gleichwertig: f′ wechselt bei x0 das Vorzeichen.
f″(x0) = 0 heißt „keine Aussage“, nicht „kein Extrempunkt“ — dann Vorzeichen von f′ links und rechts prüfen.
  1. Funktion 2, f′ und f″ ausgeblendet: Schieben Sie x0 von links nach rechts. Wo ist die Steigung null, wo negativ? Erst dann f′ einblenden und vergleichen.
  2. Funktion 3: f′(0) = 0 — aber ist (0 | 0) ein Extrempunkt? Was zeigt f′ links und rechts von 0, was zeigt f″(0)?
  3. Funktion 4: Rechnen Sie die vier Schritte zuerst selbst im Heft. Decken Sie dann Schritt für Schritt auf und vergleichen Sie.
  4. Funktion 5: Warum liefert Schritt 2 keinen Kandidaten? Was heißt das für den Graphen von f?
